# Integration examples

## Isolated performance fixture

The separate [performance fixture](performance/README.md) uses the library with system fonts and plain HTML. It has controls and reproducible URL settings for background, paper, endings, shadows, width, and content length. Serve the repository and open <http://localhost:8000/examples/performance/>, or use the [hosted preview](https://adrian729.github.io/elder-scrolls/examples/performance/?surface=walnut&width=900). The original showcase remains available.

## Plain JavaScript

From the repository root, run `python3 -m http.server 8000` and open <http://localhost:8000/examples/vanilla/>. No npm, framework, or build step is needed. The example uses the checked-in native ES modules and relative CSS/image files.

The [browser ZIP](https://adrian729.github.io/elder-scrolls/elder-scrolls-browser.zip) contains the same example at its root, the native modules, a classic-script global build, CSS, and assets. Extract it and serve the folder over HTTP; native module imports do not work reliably from `file://`.

## React

Requires a current Node version supported by Vite 8.

```sh
cd examples/react
npm install
npm run dev
```

This example uses `file:../..` to install the local library. Replace that dependency with `^0.1.1` to use npm. For release verification, install the `.tgz` generated by `npm pack` instead; see [the integration guide](../docs/INTEGRATION.md).

The example runs under React Strict Mode and exercises changing paper/endings/shadows, growing content, mounting/unmounting, controlled input state, table switching, and two independent sheets.
