# Demo illustrations

Selected 256px lossless WebP variants from [adrian729/medieval-cutouts](https://github.com/adrian729/medieval-cutouts), copied without modifying the image bytes at the repository owner's request. See `sources.json` for the original paths, dimensions, and descriptions.

These manuscript-style cutouts are demo content, separate from the generated parchment textures. They are excluded from the npm library. The source collection does not currently declare an image license; Elder Scrolls' MIT license does not grant a separate license to these illustrations.
